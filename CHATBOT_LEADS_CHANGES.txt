CHATBOT — LEAD-ONLY MODE (no AI / no website data fetching)
════════════════════════════════════════════════════════════

HOW THE CHATBOT WORKS NOW (design unchanged)
  1. Welcome screen → Start Chat
  2. Step 1: Name  (greetings like "hi" rejected as names)
  3. Step 2: Phone (10-digit Indian mobile validation)
  4. Step 3: Email (format validation)
  5. Step 4: User types their query
  6. Lead is saved →  POST /api/chat/lead/   ← the ONLY API call
  7. Bot replies: "Our team will contact you at <phone> shortly."
  8. Any further typed messages get a fixed reply:
     "Thank you for your message. Our team will contact you shortly.
      For urgent queries call <phoneNumber>."
     → NO backend call, NO AI, NO services/portfolio/FAQ data fetching.
  9. Returning users the same day skip the form and get the
     "Welcome back — team is working on it" message.

FRONTEND
  frontend/ChatbotWidget.tsx  → lead-only version (design identical)

BACKEND (chat app)
  POST /api/chat/lead/  → saves lead (used by the widget)
  POST /api/chat/       → old AI chat endpoint still exists but the
                          widget NEVER calls it. Remove later if unused.

DASHBOARD
  /dashboard/chat-leads/          → list (Pending/Resolved, search,
                                    Excel/PDF export, inline status)
  /dashboard/chat-leads/<id>/     → lead detail + admin note
  Home page                       → stat card + Recent Chatbot Leads

TO DEPLOY
  1. python manage.py migrate chat
  2. Restart server → open /dashboard/chat-leads/
  3. Use frontend/ChatbotWidget.tsx in your Next.js site:
       <ChatbotWidget apiBase="https://api.kavalakat.com/api" />
