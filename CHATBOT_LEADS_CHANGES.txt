TO DEPLOY
  1. python manage.py migrate chat        (creates the chat_chatlead table)
  2. (optional) pip install openpyxl      (real .xlsx export; CSV fallback otherwise)
  3. Restart the server → open /dashboard/chat-leads/
  4. Use frontend/ChatbotWidget.tsx in your Next.js site:
       <ChatbotWidget apiBase="https://api.kavalakat.com/api" />

NOTE: your events app has a pre-existing duplicate-table quirk
(EventImage is created in both 0001 and 0002). On a FRESH database run:
    python manage.py migrate events 0001
    python manage.py migrate events 0002 --fake
    python manage.py migrate
On your existing database this does not matter.
